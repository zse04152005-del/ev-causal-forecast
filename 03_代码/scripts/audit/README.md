# 数据核查脚本（阶段 2，2026-09-27）

设计前的数据核查脚本，输出写到 `02_数据/processed/audit/`（说明见该目录的 README）。阶段 3 会把其中需要长期使用的部分（冻结检测、分区与坐标、定价分类、功能区聚类）重构进 `src/data/`，这里保留原样以便复现。

| 脚本 | 内容 |
|---|---|
| `_paths.py` | 路径约定（输入、输出目录）与中文字体查找 |
| `shp.py` | 不依赖 GIS 库的 shapefile 读取、Web 墨卡托与经纬度互换、GCJ-02 与 WGS84 互换、点落区 |
| `check1.py` | 目标变量分布、零值、时长与占用的时序对齐、价格时刻表的初步检查 |
| `check2.py` | 桩数与单位、分时定义与切换事件、距离与环带、切分日期与需求低谷 |
| `check3.py` | 日内价格结构；分时 vs 固定按时刻平均的需求跳变（发现构成混杂） |
| `check4.py` | 各时刻的切换方向分布、时刻表的跨日与跨月变化、弱变动小区 |
| `check5.py` | 弱变动小区的价格样例；连续相同值的检测 |
| `check6.py` | 10 月底数据冻结期的定位；全市异常小时标记 |
| `check7.py` | **冻结掩码**；识别可行性回归（设计 A–D） |
| `check8.py`、`check9.py` | 分区面与站点、POI 的坐标系核对 |
| `check10.py` | POI 落区、静态特征、功能区聚类 |
| `check11.py` | 假设 A 的检验（固定效应解释的价格方差）；测试期冻结分布 |
| `check12.py` | 锚定格子（功能区 × 情境）的干净切换事件数 |
| `fig_audit.py` | 数据核查四联图 |
| `run_all.sh` | 按依赖顺序全部重跑 |
