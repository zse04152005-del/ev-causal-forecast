## 二、本项目的设计语言

### 2.1 颜色语义（全项目统一，框架图和数据图都用）

**v1.1 色板**（v1 的紫与蓝在红绿色盲下几乎无法区分，已弃用）：

| 语义 | 线条 / 描边 | 浅填充 | 中间色 | 深填充 | 用于 |
|---|---|---|---|---|---|
| **需求**（利用率、时长、电量）及潜在特征 | `#4072B7`（蓝） | `#EEF5FF` | `#D6E8FF` | `#B6D3FC` | 需求序列、骨干网络、分位数头、基线需求 |
| **价格信号**（电价、服务费、环带暴露） | `#CA710A`（橙） | `#FDF2EA` | `#FBE1CC` | `#F2C8A7` | 价格输入、价格响应模块、环带着色 |
| **外生协变量**（天气、日历、POI） | `#3B9D5C`（绿） | `#EDF8EF` | `#D4EED9` | `#B2DEBC` | 协变量输入与嵌入 |
| **因果锚定**（固定值，不是可训练参数） | `#6D2D98`（紫，**粗虚线**） | `#F7F2FD` | `#EEE0FB` | `#DDC6F2` | 因果识别模块、锚定值、截断反馈 |
| **输出与预测区间** | `#B73138`（红） | `#FFF1EF` | `#FFDCDA` | `#F9C1BD` | ŷ、训练损失、保形校准与区间 |
| **中性**（图结构、辅助运算） | `#8C8C8C`（灰） | `#F3F3F3` | `#E6E6E6` | `#D2D2D2` | 图结构、tanh / σ / ReLU / BN、冻结点 |

- 校验（五个有色角色，全部两两组合，OKLab 色差 × 100）：亮度带、饱和度下限、与底色对比度全部通过；色盲模拟下最小色差 8.1（绿—橙，红绿色盲）、蓝黄色盲 7.8；正常色觉下最小色差 15.3（红—橙）
- 颜色从不单独承担含义：每条数据流都有数学符号标注或图例；因果锚定另用粗虚线，梯度另用点线

**最醒目的元素**：因果先验通过紫色虚线进入价格响应头，这是论文的核心卖点，线宽比其他箭头略粗，并在图例中单独说明。

数据图和结果图中的对应：
- 分时电价小区 = 橙色，固定电价小区 = 灰色
- CPA-STGNN（我们的模型）= 红色，最强基线 = 蓝色，其他基线 = 灰色系
- 因果估计值与置信区间 = 紫色

### 2.2 符号

| 符号 | 含义 |
|---|---|
| ⊕ | 逐元素相加 |
| ⊗ | 逐元素相乘 |
| © | 拼接 |
| exp(·) | 指数变换（价格响应进入乘性结构） |
| 实线箭头 | 数据 / 特征流 |
| 紫色粗虚线箭头 | 固定的因果锚定值进入模型（缓冲区，不是数据流，也不是可训练参数） |
| 灰色点线箭头 | 训练梯度 ∇ |
| ✂ | 截断反馈：预测损失的梯度不回传到锚定值 |
| 紫色挂锁 | 固定缓冲区，不可训练 |
| 一串灰色 × + 红色斜线 | 冻结（插补）的数据点被掩码。**不用 ❄**：框架图中雪花一般读作"冻结的权重" |
| 虚线点框 + "×8"（总框架图）；点画线叠放框 + "×8"（模块图） | 重复的时空层（仿 Graph WaveNet 原图与 iTransformer 的 "L×"） |
| ○ | 拼接 |
| 尖角 ^ | 下面一行的数据整体进入上面的模块（仿 PAG） |
| 点线外框 | 训练前一次性完成的离线模块（因果识别） |
| 虚线方框 | 示意部分 |

### 2.4 理论图形与图标（v1.3）

- **总框架图以理论图形为主**（参照 `论文图表模板/01_模型总框架图/` 的 PAG、PIAST、iTransformer、Graph WaveNet）：
  - 左侧行标签 + 竖向双箭头（Raw data / Features / Model），数据行用灰色虚线框，行与模块之间用尖角 ^ 连接
  - 各小区的序列画成叠放卡片上的一排节点圆点 $x_1\dots x_N$，右下角斜箭头标时间轴；拼接用空心圆 ○
  - 网络层画成圆角方块（与模块图同色），激活函数用椭圆，门控 ⊗、残差 ⊕、重复层标 "×L"
  - 模块用实线外框，训练前一次性完成的离线模块用点线外框（仿 PAG 的预训练模块）
- **图标只作点缀**：全市共用的协变量（日历、天气）、POI（定位）、损失（pinball 检查函数）、校准（α 轨迹）、输出（"历史 + 预测区间"小图）、因果识别的四个小图；线条图标、描边为主、浅色填充，颜色跟随所属数据流
- 不用写实插画、emoji 风格或装饰性图标；**只借鉴画法，不复制范例图形**
- **模块图不写成段文字**：机制用小图表达（例如直方图 → 区间 → 覆盖 → 更新的一条机制链），公式与阈值写进图注
- 图元与每个图形的含义：`04_图表/绘图脚本/theory.py`、`icons.py`，`04_图表/README_图稿说明.md` 第 2.4 节

### 2.5 制作流程（沿用之前项目的做法）

1. **草图**：先手绘或用 draw.io 画结构草图，核对与模型设计文档一致
2. **（可选）AI 风格稿**：生成风格探索稿，存入 `04_图表/AI草图/`，**只看风格，不用于正文**
3. **Python 生成 SVG**：参照 `参考_之前项目的绘图脚本_draw_overall.py`，用脚本绘制可编辑 SVG（结构准确，方便反复修改）
4. **导出** PDF 和 PNG
5. **核对**：逐条箭头对照代码计算图；写入 `04_图表/README_图稿说明.md`（设计语言、每张图的计算逻辑、创新点与图中元素的对应、建议图注）

### 3.2 模块架构图（(b)(c)(d) 放大，也可单独成图）

- **(b) 价格响应头**：节点嵌入 + 时段嵌入 + 功能区类型 → MLP → −softplus → β ≤ 0；右侧紫色框表示锚定损失 $\sum_g ((\bar\beta_g - \hat\beta_g)/\mathrm{se}_g)^2$
- **(c) 空间溢出**：以一个小区为中心画 0–1、1–2、2–3、3–5 km 同心圆环，环内小区着色表示价差；右侧画 δ(d) 随距离指数衰减的小曲线
- **(d) 保形校准**：时间轴上的分位数区间 → 校准集残差 → α_t 在线更新（小折线示意）→ 校准后区间

## 四、数据图与结果图（阶段 5、9 使用）

| 类型 | 规范 |
|---|---|
| 地图 | 小区边界细灰线；分时电价小区橙色填充，固定电价小区浅灰；比例尺 + 指北针；坐标系统一为 WGS84 |
