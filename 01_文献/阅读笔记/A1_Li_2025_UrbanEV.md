## 1. 研究问题

提供一个包含价格、天气、POI、空间结构的城市级 EV 充电开放基准数据集，并给出统一的预测基准。

## 2. 数据构造（写论文数据章节时逐条引用）

| 项目 | 内容 |
|---|---|
| 来源 | 司机查找公共充电站的手机平台，逐桩抓取状态（忙 / 闲）、额定功率、电价、服务费、坐标 |
| 时间 | 2022-09-01 至 2023-02-28，原始 5 分钟粒度；发布版为逐小时（4,344 个时间步） |
| 原始规模 | 1,682 个充电站、24,798 个桩 |
| 发布规模 | 过滤后 **275 个交通小区**、1,362 个站、17,532 个桩（原 331 个小区，去掉占用率方差 < 0.001 或零值超过 30% 的小区） |
| 占用 o | 站内"在用桩数"；桩在**相邻两个时间点都为"忙"**才算在充电 |
| 时长 d | 在用桩数 × 时间间隔（5 分钟），按小时求和 |
| 电量 v | 时长 × 桩的**额定功率**（可能高估）；另提供 `volume-11kW.csv`：直流桩按 11 kW（特斯拉 Model Y）估算 |
| 价格 pe、ps | 电价、服务费；**聚合到小时时取的是某一时点的瞬时值，不是小时平均**（论文原话的意思是这样更能保留原始模式） |
| 天气 | 气温 Ta、气压 P、相对湿度 h，来自机场站和市中心站，**全市共享**（没有空间差异） |
| 空间 | 邻接矩阵（两小区是否相邻）、距离矩阵（小区质心欧氏距离，米） |
| 静态 | POI 三类（餐饮、商务住宅、生活服务，2022 年 12 月采集）、面积、道路长度、桩数 |
| 清洗 | 删除负价格、桩数不一致的记录后前向 / 后向填充；IQR 异常值检测（系数取 4，而不是常用的 1.5），异常值用相邻有效值的均值替换 |

描述统计（表 2，小区级）：白天平均占用率 0.24、夜间 0.30；电价白天均值 0.98、夜间 0.93；服务费均值约 0.70–0.73；气温 8.3–34.7 ℃。

## 3. 基准实验设置

- **时间序列交叉验证 6 折**：每折多加一个月数据，其中 80% 训练、10% 验证、10% 测试
- 预测步长：3、6、9、12 小时
- 指标：RMSE、MAPE、RAE、MAE
- 基线：LO（上一时刻值）、AR、ARIMA、FCNN、LSTM、GCN、GCN-LSTM、ASTGCN、TimesNet、TimeXer

## 4. 主要结果（我们的基线数字要与之对齐）

小区级占用率预测（表 3，平均值）：

| 模型 | RMSE (×10⁻²) | MAPE (%) | MAE (×10⁻²) |
|---|---|---|---|
| LO | 13.09 | 43.02 | 7.83 |
| LSTM | 10.28 | 43.99 | 6.79 |
| GCN-LSTM | 9.53 | 43.59 | 6.58 |
| ASTGCN | 10.13 | 44.64 | 6.75 |
| TimesNet | 9.54 | 35.20 | 5.99 |
| **TimeXer** | **9.24** | **32.74** | **5.61** |

**因子实验（表 5）——对我们非常重要**：

- 单独加入电价 pe 后，TimeXer 的 RMSE 从 7.95 **变差**到 8.50；四个模型平均 RMSE 从 8.99 变差到 9.10
- 只有特定组合（Ta + pe、ps + pe）才有改善；五个外生变量全部加入反而不一定更好
- 论文结论是"需要能有效处理多维辅助信息的先进模型"

**这正是我们的动机之一**：把价格当作普通协变量直接喂给模型，对预测几乎没有帮助甚至有害。原因很可能是价格与需求高峰高度共线（内生性），模型难以分离价格的真实作用。我们用因果结构把价格的作用"单独建模"，有望让价格信息真正发挥作用。

## 5. 局限与注意事项

| 问题 | 对我们的影响与对策 |
|---|---|
| 价格取瞬时值 | 分时电价切换若发生在小时内部，逐小时数据会错位，**断点分析必须用 5 分钟数据** |
| 小区价格是站点均价 | 跳变幅度被稀释；需用站点级数据复核（已在大纲中列出） |
| 天气全市共享 | 天气只能作为时间维度控制变量，不能解释空间差异 |
| 电量按额定功率推算 | 用 `volume-11kW`、`duration`、`occupancy` 做稳健性检验 |
| 过滤掉了低活跃小区 | 结论只适用于活跃小区，论文中要说明 |
| 只有 6 个月 | 没有夏季；用 CHARGED 深圳子集（2023 年 4–9 月）可以补充 |
| 论文中价格单位写作"Yuan/hour" | 与 GitHub 说明（元/kWh）不一致，**以 GitHub 为准，并在数据审计中核对数值范围**（均值约 0.98，符合元/kWh） |
