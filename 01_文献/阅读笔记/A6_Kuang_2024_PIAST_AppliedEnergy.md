# A6 Kuang et al. (2024) PIAST：物理约束图学习的充电需求预测与定价

- **引用**：Kuang, H., Qu, H., Deng, K., Li, J. (2024). A physics-informed graph learning approach for citywide electric vehicle charging demand prediction and pricing. *Applied Energy*, 363, 123059. https://doi.org/10.1016/j.apenergy.2024.123059
- **等级**：领域 SCI（**我们首选的目标期刊**）
- **笔记**：Claude 初稿（2026-09-27），待你精读核对
- **重要程度**：★★★★★（**模型层面最直接的竞争对手**，比 PAG 更接近我们的 CPA-STGNN）
- **代码**：https://github.com/kuanghx3/PIAST （可直接作为基线运行）

## 1. 研究问题

构建一个既能准确预测充电需求、又"在经济上可解释"（能反映价格弹性和溢出效应）的模型，用于辅助定价。

## 2. 数据

与 A3、A4 相同：ST-EVCDP，深圳 247 个小区（全市 532 个中选出），57 个分时电价小区，2022-06-19 至 07-18，5 分钟粒度；18,061 个桩（快充 2,056、慢充 16,005）；需求为占用；**按时间 7:3 划分训练集和测试集**（没有单独的验证集）。

## 3. 方法

三个模块：

| 模块 | 结构 |
|---|---|
| 特征工程 | 把**预测时刻的价格** $P_{t+\tau'}$ 重复到窗口长度，与历史需求拼接，用二维卷积融合（使价格信息能在后续图卷积中传播，从而体现溢出） |
| 时空双注意力 | 多头 GAT（2 层、4 头）+ LSTM + 时间注意力 + MLP 解码 |
| **物理约束训练（PINN）** | 为每个区域设一个**可学习的弹性参数** $\varepsilon^*$；三个损失：预测损失 $L_D$、弹性损失 $L_\varepsilon$（用自动求导使 $\frac{\partial d}{\partial p}\cdot\frac{p}{d} = \varepsilon^*$ 成立）、参考知识损失 $L_K$（把 $\varepsilon^*$ 拉向参考值 $\varepsilon_K$） |

**三步训练**：
1. 预训练：$L_D + L_\varepsilon + \alpha_1 L_K$，$\alpha_1$ 较大（如 1），强先验引导
2. 提示（prompting）：$L_D + L_\varepsilon + \alpha_2 L_K$，$\alpha_2$ 较小（如 0.1），"让模型学习数据本身的价格规律"
3. 微调：只用 $L_D$，**冻结 $\varepsilon^*$**

**参考弹性** $\varepsilon_K = -0.45$，依据是全球家庭用电弹性（−0.45）、加拿大汽油（−0.40）、圣地亚哥夜间低价充电（约 0）。

其他设置：窗口 12 步（60 分钟）；预测 15、30、45、60 分钟；预训练 300 轮、提示 200 轮、微调 500 轮；MSE 损失；Adam，batch 1024，学习率 0.001；NVIDIA RTX 4000。

## 4. 主要结果

| 结果 | 数值 |
|---|---|
| 精度 | 相对各基线平均提升 14.78%；相对 PAG 平均提升 8.00% |
| 消融 | 去掉 PINN 模块精度只下降约 2.65%，论文称其主要作用是"揭示弹性、增强可解释性" |
| **点弹性（57 个分时电价小区）** | 平均 **−0.119（15 分钟模型）至 −0.149（60 分钟模型）**；最大 −0.41 左右，最小约 −0.01 |
| 弧弹性（价格 ±5%、±10%、±15%） | 平均 **−0.078 至 −0.086** |
| 定价实验 | 用模型预测控制（MPC）把午间价格调到当日最高（1.41 元/kWh），预计需求下降 10.26% |
| 泛化 | 随机去掉 20%（49 个）小区，重复 5 次，仍优于其他模型 13.51% |
| 训练时间 | 预训练和提示 3.08 秒/轮，微调 1.49 秒/轮 |

结论称深圳充电需求"非常缺乏弹性"，发达区域和桩多的区域弹性更高；降价比涨价的弧弹性更高。

## 5. 价格与因果的处理方式 ⭐（与我们的关键区别）

- PIAST 的"弹性"是一个**被参考值 −0.45 牵引的可学习参数**，而不是从数据中识别出来的因果效应
- 在分时电价小区，价格几乎是时段的确定函数，价格与时间模式高度共线，**仅靠拟合数据无法把"价格效应"和"时段效应"分开**。因此学到的 $\varepsilon^*$ 主要取决于参考值、训练顺序和损失权重
- **同一份数据、同一个研究团队，两篇论文的弹性相差 5–9 倍**：
  - PIAST（参考值 −0.45）：平均点弹性 −0.12 至 −0.15
  - Kuang et al. 2024（A4，基于 PAG，先验 −1.48 / −0.228）：平均弹性 −0.76
  - 两者用的都是 ST-EVCDP 的 57 个分时电价小区、同一时段
  - **不对称性结论也相反**：A4 称用户对涨价更敏感；本文称对降价更敏感（第 4.7 节，但差别很小：降价弧弹性 −0.083 至 −0.086，涨价 −0.078 至 −0.081）
  - 写论文时要说明两者的弹性定义和测试期略有不同（A4：±1 个标准差脉冲、7 月 13–18 日；本文：自动求导点弹性与 ±5–15% 弧弹性、7 月 10–18 日），但 5 倍以上的差距不是定义差异能解释的
  - A4 引用了本文，却没有讨论两者的差异
- 这是**"从预测模型中读弹性"不可靠的最直接证据**，而且出自他们自己发表的论文。我们的引言可以直接引用这一对比

## 6. 与 CPA-STGNN 的逐项对比

| 维度 | PIAST | CPA-STGNN（本项目） |
|---|---|---|
| 弹性来源 | 可学习参数 + 文献参考值 −0.45 | 本数据的准实验识别（差分断点），带标准误 |
| 先验强度 | 人工设定 α（1 → 0.1 → 冻结） | 按因果估计的标准误自动加权（估计越精确约束越强） |
| 弹性如何进入模型 | 软约束：自动求导的偏导数损失 | 结构约束：乘性形式 $g \cdot \exp(\beta\,\Delta\log p)$，$\beta$ 就是弹性 |
| 可识别性 | 未讨论；价格与时段共线时弹性不可识别 | 明确承认纯预测训练无法识别弹性，由外部因果估计提供识别信息 |
| 溢出 | 隐式（二维卷积 + GAT） | 显式参数化（距离衰减），由环带因果估计锚定 |
| 不确定性 | 无 | 分位数输出 + 自适应保形校准 |
| 评价 | 精度 + 弹性是否"合理" | 精度 + 校准 + 反事实一致性（真实切换点 + 半合成真值）+ 先验敏感性 |

## 7. 在我们论文中的用法

1. **必选基线**：官方代码开源，直接运行
2. **先验敏感性实验的对象**：把参考值 $\varepsilon_K$ 设为 −0.2、−0.45、−0.76、−1.48、−3，看学到的弹性是否随之移动
3. **半合成实验的对象**：在已知真实弹性的数据上，检验 PIAST 能否还原真值（预计在价格与需求高峰强相关时失败）
4. **引言动机**：同一数据上 −0.76 与 −0.14 的矛盾
