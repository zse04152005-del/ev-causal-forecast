## 1. 研究问题

估计深圳公共 EV 充电需求的价格弹性，分析其在时段、功能区（CBD 与非 CBD）之间的差异，并量化价格变化引起的空间溢出（向邻区转移的比例和范围）。

## 2. 数据

| 项目 | 内容 |
|---|---|
| 来源 | ST-EVCDP（同一团队发布，https://github.com/IntelligentSystemsLab/ST-EVCDP），手机应用抓取的桩位实时状态 |
| 时间 | 2022-06-19 至 2022-07-18，**仅 30 天**，5 分钟粒度，8,640 个时间步 |
| 空间 | 247 个交通小区，1,006 条邻接边；18,061 个充电桩 |
| 处理组 | **57 个小区实行分时电价**，其余为固定电价；CBD 62 个小区 |
| 需求变量 | 占用（在用桩数 / 占用率），**不是电量** |
| 价格变量 | 电价 + 服务费之和（论文中不区分两者） |
| 切分 | 按时间 6:2:2，第 1–18 天训练、19–24 天验证、25–30 天测试 |

描述统计（论文表 2）：白天平均占用率 24.50%，夜间 31.46%；夜间均价 0.93 元/kWh，比白天低；CBD 白天均价比其他区域高 6.19%。

## 3. 方法（三步）

1. **相关性检验**：对 57 个分时电价小区做 Pearson、Spearman 相关，以及 Granger 因果检验（F 检验、卡方检验、似然比检验，最多 12 期滞后，即 1 小时）。
2. **时空回归模型**：用同一团队的 PAG 模型（见 A3）预测 30 分钟后的占用：二维卷积融合特征 → 两层多头图注意力（GAT）→ LSTM → 时间模式注意力（TPA）→ 多层感知机。**模型经过"知识嵌入的元学习"预训练：按先验弹性生成伪样本，与真实样本混合训练，伪样本比例逐轮递减（第 e 轮为 1 − e/1000）**。
3. **脉冲响应分析**：在训练好的模型输入中，把某小区的价格加减一个标准差，比较预测值的变化：

   $$\Delta y_i = F(o, c + \Delta c_i) - F(o, c)$$

   用点弹性公式 $\xi_i = (\Delta y_i / y_i) / (\Delta c_i / c_i)$ 计算弹性；邻区响应与本区响应之比定义为溢出强度 $\eta'$（1 跳）、$\eta''$（2 跳）。

## 4. 价格与因果的处理方式 ⭐（本项目最关心）

- 论文自称做了"Granger 因果检验"，但 Granger 因果只是**预测意义上的先后关系**，不是结构性因果。
- **弹性来自对预测模型的扰动**，本质上仍是模型学到的相关关系，没有任何外生变动的识别策略（没有对照组、没有断点、没有工具变量）。
- **内生性的直接证据就在论文里**：57 个分时电价小区中，8 个与价格正相关（7 个在 CBD），42 个负相关。论文把正相关解释为出行习惯（白天去 CBD），这恰恰说明**价格高的时段本身就是需求高的时段**，价格与需求共同受时段、区位驱动。
- **先验依赖（最关键的问题）**：本文沿用 PAG 模型（A3）及其"知识嵌入元学习"，即按先验知识（"涨价后需求通常下降多少"）生成伪样本、与真实样本混合预训练。**本文没有写明所用的具体先验值**；PAG 论文中用的是 −1.48（北京，Bao et al. 2021）和 −0.228（全球家庭用电）。本文得到的 −0.76 恰好落在这两个值之间。**估计出的弹性在多大程度上反映数据、多大程度上反映注入的先验，论文没有检验**（精读时请再确认原文第 3.2 节和第 4 节是否另有说明）。
- **不确定性处理不当**：论文称均值的 95% 置信区间为 $[\bar{x} - 10^{-6}, \bar{x} + 10^{-6}]$，理由是"样本量大"。但这 196,992 个"样本"是对同一个训练好的模型反复扰动得到的，并不是独立观测，这个区间**完全没有反映模型估计的不确定性**。
- 测试期只有 6 天（7 月 13–18 日），脉冲幅度设为价格标准差，结论能否外推到其他时期存疑。

## 5. 实验设置

- 预测步长：30 分钟（依据深圳平均通勤 36 分钟）；回看窗口 12 步（60 分钟）
- GAT 2 层、4 个注意力头；预训练 200 轮、微调 1000 轮，早停耐心 100 轮
- 学习率：预训练 0.005，微调 0.001
- 指标：RMSE、MAE、MAPE、RAE

## 6. 主要结果（便于直接对比）

| 结果 | 数值 |
|---|---|
| 全市平均价格弹性 | **−0.7581** |
| CBD / 非 CBD | −0.7236 / −0.7654 |
| 弹性方差（全部 / CBD / 非 CBD） | 0.1016 / 0.0683 / 0.1037 |
| 溢出强度（涨价 / 降价，1 跳） | 89.48% / 53.88% |
| 溢出强度（2 跳，涨价 / 降价） | 0.63% / 0.35% |
| 1 跳 / 2 跳平均交叉弹性 | 0.5667 / 3.70×10⁻⁵ |
| 溢出范围 | 3.45 km（95% 的小区交叉弹性 > 0.1 的最大距离） |
| 相关性 | 57 个小区平均 Pearson、Spearman 绝对值 0.5439、0.5437；55/57 通过 Granger 检验 |
| 预测精度 | RMSE 0.1811、MAE 0.3220、MAPE 16.87%、RAE 19.63%；比 VAR 平均提升 61.3%，比 DCRNN、AST-GAT 提升 5.9%。**注意**：MAPE、RAE 与 PAG 论文（A3）完全相同，但 RMSE、MAE 不同（A3 报告 RMSE 0.0573、MAE 0.0393），且本文 MAE 大于 RMSE，数学上不可能，疑为笔误。引用精度数字时以 A3 为准 |

其他结论：
- 涨价比降价更能改变弹性（用户对涨价更敏感）
- 占用率低于 15% 或高于 70% 时需求缺乏弹性，15%–70% 时弹性分布很宽（−0.013 至 −1.877）

## 7. 局限与可被我们超越的地方 ⭐

| 局限 | 我们的做法 |
|---|---|
| 弹性来自预测模型扰动，没有因果识别 | 利用分时电价切换时刻做差分断点（固定电价小区作对照），得到准实验意义上的弹性 |
| 弹性可能受预训练先验（−1.48、−0.228）主导 | **设计"先验敏感性实验"**：用不同先验训练同类模型，检验扰动出来的弹性是否随先验移动。如果是，就直接证明了现有方法的缺陷 |
| 置信区间实际上不反映估计不确定性 | 给出按小区聚类的标准误和置信区间 |
| 只有 30 天数据、6 天测试 | UrbanEV 覆盖 6 个月（2022-09 至 2023-02），跨季节 |
| 需求只用占用率（可用性口径） | 同时用电量、时长、占用率四个口径做稳健性检验 |
| 电价与服务费合并 | UrbanEV 分别提供两者，可以区分 |
| 溢出只看 1 跳、2 跳邻接 | 用距离环带（0–1、1–2、2–3、3–5 km）估计连续的衰减曲线 |

**注意**：UrbanEV 与 ST-EVCDP 的时间段不同（UrbanEV 为 2022-09 至 2023-02），我们的弹性与 −0.76 的对比要说明时期差异。
