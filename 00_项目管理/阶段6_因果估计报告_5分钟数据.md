# 阶段 6（第一版）：站点级 5 分钟数据上的价格弹性估计

> 日期：2026-09-29｜对应大纲阶段 5.1 与 6.1–6.3、6.5、6.7｜代码：`03_代码/src/causal/switch_5min.py`、`panel_models.py`，脚本 `scripts/estimate_causal_5min.py`、`boot_cd_diff.py`、`estimate_panel_supp.py`，审计 `scripts/audit/check13_5min.py`｜结果：`05_实验结果/因果估计/5min/`｜图：`04_图表/数据与EDA图/Fig_S_causal_5min.*`
> **所有估计只用训练期（2022-09-01 至 2023-01-05）。这是第一版结果，还有 6.4、6.6 和若干稳健性没做完（第七节）。**

## 一、结论（先看这里）

1. **弹性在这份数据里是弱识别的。** 主设计 D（站点内跨日变动）在 3 小时窗口的估计是 **β̂ = −0.25**（小区聚类标准误 0.22；按小区自助法的标准误 0.40）；1 小时窗口约 −0.05（标准误 0.13）。点估计大致在 −0.05 到 −0.3，区间很宽，包含 0，也包含 −0.7。
2. **设计 C（跨站点比较）给出较大的负值（−0.4 到 −0.7），但没有通过安慰剂检验**：把切换时刻平移 1–4 小时后，C 仍出现 +0.07 到 +0.23 的"假效应"（有的显著）；D 的安慰剂全部在 0 附近（−0.03 到 +0.01，标准误 0.01–0.04）。所以 C 被站点自己的作息混杂，**主设计保持 D（决策 D9）**。D 与 C 之差 +0.25，自助法 95% 区间 [−0.73, +0.94]，不显著。
3. **两个独立的补充估计与 D 一致**：逐小时面板 PPML（小区 × 周内小时、日期 × 时刻固定效应）−0.26（0.25）；DML（梯度提升，按小区分组交叉拟合）−0.22（0.23）。
4. **和文献对照**：这个量级接近 PIAST 报告的 −0.1 到 −0.15，明显小于 Kuang et al. (2024) 的 −0.76（来自预测模型的脉冲响应）。这支持论文的核心论点：模型扰动得到的弹性依赖先验。
5. **事件研究显示切换后有一个短期响应**（设计 C：切换后 30–60 分钟需求下降最多，约 −0.7，2–3 小时后回到 −0.3），但该响应含有站点作息的混杂成分（C 的安慰剂为正）；设计 D 的路径没有清晰的断点（切换前后都在 −0.25 附近，标准误约 0.25）。
6. **空间溢出 δ 没有识别出来**（各设计、窗口下符号和大小都不稳定，标准误比估计值还大）。模型里 δ 继续用 0；溢出只作为探索性结果。
7. **格子（功能区 × 情境）估计噪声很大**，建议锚定用"全市一个 β̂"（见第五节），格子表放附录作异质性的探索性证据。
8. **半合成验证（第九节，2026-09-29 晚补充）**：
   - 设计 D 没有衰减偏误；估计小主要是因为充电时长是"存量"，切换后窗口内只有新到达的车辆响应。
   - 按平均会话 60 分钟换算，与真实估计相符的到达弹性约 −0.33（se 0.20）；会话 120 分钟时约 −0.65（与第 4 条中 Kuang 的 −0.76 不再矛盾）。
   - 设计 C 的估计可以完全由站点平均日内曲线复现，与价格效应无法区分。

## 二、数据与方法

| 项目 | 做法 |
|---|---|
| 数据 | UrbanEV 站点级 5 分钟数据（D3 压缩包 `station-processed/features`，1,423 站；限定主数据的 1,362 站），转为压缩 npz 放在 `02_数据/interim/fiveMin/`；价格 = 电价 + 服务费（与主数据一致） |
| 价格过渡 | 站点价格在 15 分钟内连续变动的合并成一次过渡（例如 19:00 → 19:05 分批变价）；净变动 |Δln p| ≤ 0.01 的不算（含 16:30→16:35→16:40 的瞬时尖峰）；x = 过渡的对数价格净变动 |
| 干净窗口 | 前窗（W 步）内价格不变；过渡结束后到后窗末尾价格不变；两个窗口没有无效点；法定假日前后一天排除 |
| 无效点 | 站点时长为负（最低 −65）、超过桩数上限、缺失；站点级"占用与时长同时连续 24 小时不变"（占用 > 0）或 48 小时不变；小区级小时冻结掩码（覆盖训练期约 5%）。站点级不能沿用小区级的 6 小时规则：站点只有十几根桩，同一批车连续停几小时时数值本来就不变 |
| 观测集 | 分时站点（训练期 ≥ 50% 的天有日内变价，128 个；与小时数据的 90 个分时小区完全对应）在自己有过切换的"5 分钟时刻槽"上的全部干净观测（有变价与无变价的日子）。设计 A/B 另加 80 个随机固定电价站点（种子固定）作对照 |
| 估计量 | **PPML（主）**：切换后/前窗口的时长计数（桩·小时）之比，条件泊松 ⇔ 后窗份额的二项 logit，logit = β·x + 固定效应；给两个窗口各加 0.1 桩·小时防止 0；对数比 OLS（ε = 0.01）作对照 |
| 固定效应 | A：日期×时刻槽（分时 + 固定站点）；B：A + 站点×时刻槽；C：分时站点，日期×时刻槽；**D（主）**：C + 站点×时刻槽 |
| 标准误 | 按小区聚类（CR1）。对比：按站点、按日期聚类，小区与日期双向聚类（`cluster_compare.csv`）；小区自助法（`boot_cd_diff*`） |
| 与小时数据的口径 | 窗口 3 小时（W=36 步）对应锚定的 `window_3h_log_mean`；短窗口（30–120 分钟）只作稳健性 |
| 溢出暴露 | 邻区 Δℓ（价格对参考价格的对数偏离）的环带均值，**窗口后减窗口前**；与模型的 S 同一口径（决策：统一用 `ring_exposure`，固定电价邻区自动为 0 变化） |

## 三、阶段 5.1 审计发现（`scripts/audit/check13_5min.py`）

- **站点级分型与小时数据完全一致**：90 个分时小区、23 个弱变动、158 个固定；站点级 128 个分时站（3,200 根桩，占主数据桩数的 18%）、43 个弱变动站、1,191 个固定站。
- 训练期 16.4 万次切换；只有 57% 落在整点/半点，11% 是 +5 分钟延迟，31% 落在其他分钟（分批变价与零星调价）。2 万次是瞬时尖峰。
- 时刻表按日变化很大：**1,647 种不同的"一日切换时刻序列"**，前 5 种只占 62% 的站点日。这是设计 D 能识别的来源，也是它识别力弱的原因（固定效应后剩下的价格变动约 2%）。
- 数据质量：站点时长有 11,200 个负值格子（0.015%，1,239 站，多在 2 月测试期），366 个超过桩数上限；已作为无效点剔除。站点汇总到小区后与官方小区 5 分钟表的相关系数 0.9956。
- 干净事件数（训练期、分时站点、无冻结）：窗口 ±30 分钟约 7.3 万；±1 小时 7.1 万；±2 小时 5.9 万；±3 小时 1.5 万（加 10 分钟甜甜圈后 7.5 千，估计变得不稳定）。

## 四、主要结果

### 4.1 规格表（PPML，结果口径 = 时长，无甜甜圈；括号内为小区聚类标准误）

| 半窗 | A | B | C | D（主） |
|---|---|---|---|---|
| ±30 分钟 | −0.16 (0.06) | −0.11 (0.11) | −0.38 (0.10) | −0.07 (0.11) |
| ±60 分钟 | −0.24 (0.09) | −0.09 (0.12) | −0.62 (0.15) | −0.05 (0.13) |
| ±120 分钟 | −0.22 (0.11) | −0.21 (0.24) | −0.63 (0.17) | −0.16 (0.23) |
| **±180 分钟（锚定口径）** | −0.21 (0.15) | −0.58 (0.33) | **−0.50 (0.23)** | **−0.25 (0.22)** |

- 加 10 分钟甜甜圈：D 为 −0.05（30 分钟）、−0.19（60）、−0.22（120），**在 180 分钟窗口变成 −1.3（0.43）**——此时干净事件只剩一半，估计不稳定，不作主结果。
- 对数比 OLS（ε = 0.01）与 PPML 方向一致：D 为 −0.10、−0.07、−0.22、−0.30。
- 换结果口径（±60 / ±180 分钟，设计 D）：占用 −0.02 / −0.09；电量 +0.05 / +0.16（标准误 0.10–0.18）。**电量口径下 D 没有负号**，与时长口径的差别应在论文里如实报告。
- 设计 A/B（固定电价站点作对照）随窗口大幅波动（B 从 −0.09 到 −0.58），只作稳健性，不作解释。
- 包含环带暴露与不包含时，自身弹性变化很小（如 D 180 分钟：−0.25 与 −0.21）。

## 九、5 分钟半合成验证（2026-09-29 晚，你确认后做）

**问题**：设计 D 的估计很小（1 小时窗口 −0.05，3 小时窗口 −0.25），是真实弹性小，还是估计量把效应压小了？

**做法**（`scripts/semisynthetic_5min.py`）：价格路径、切换时刻、无效点、样本全部用真实数据，只把 128 个分时站点的需求换成已知弹性的合成需求：
- 到达率 = 站点"工作日/休息日 × 5 分钟时刻"平均曲线（由真实时长换算）× 日因子 × 小时因子（对数正态，sd 各 0.25）× exp(β · 对数价格偏离)
- 到达数 ~ 泊松；会话时长 ~ 对数正态，平均 30 / 60 / 120 分钟；同时在充数不超过桩数；合成"时长" = 在充会话数 / 12
- β ∈ {0, −0.5, −1.0}，每格 3 个种子；用与正式估计完全相同的面板与 PPML 估计设计 C、D
- 三种结果：合成时长（stock，与真实估计同口径）、到达数（flow，没有存量稀释）、无噪声期望存量（truth，窗口口径下的"真值"）
- 校准：合成时长上非事件行的窗口对数比标准差 0.55（1 小时窗口），真实数据 0.51，噪声水平相当

**结果**（`05_实验结果/因果估计/5min/semisynth_5min_summary.csv`、`_implied.csv`；图 `Fig_S_semisynth_5min`）：

1. **设计 D 本身没有衰减偏误**：
   - 合成时长上的估计 ÷ 无噪声真值 = 0.90–1.04（各窗口、各会话时长）
   - 到达数上能还原注入的 β（斜率 0.90–1.01）
   - β = 0 时估计在 −0.03 到 +0.08 之间（3 个种子的均值）

   结论：噪声、伪计数、截断都没有把 D 明显压向 0。
2. **小估计主要来自"存量稀释"**：充电时长是存量，价格变化只影响新到达的车辆，切换前已经在充的车不受影响，所以窗口内的平均存量只部分调整。设计 D 的估计与到达弹性之比如下：

   | 平均会话时长 | 30 分钟窗口 | 1 小时 | 2 小时 | 3 小时 |
   |---|---|---|---|---|
   | 30 分钟 | 0.45 | 0.63 | 0.77 | 0.80 |
   | 60 分钟 | 0.23 | 0.37 | 0.56 | 0.59 |
   | 120 分钟 | 0.08 | 0.14 | 0.28 | 0.27 |

   这也解释了真实估计随窗口变大而变负（−0.07 → −0.25）。
3. **反推与真实估计相符的到达弹性**（四个窗口逆方差合并；各窗口之间都一致，卡方 < 1）：

   | 平均会话时长 | 到达弹性 | se |
   |---|---|---|
   | 30 分钟 | −0.18 | 0.12 |
   | 60 分钟 | −0.33 | 0.20 |
   | 120 分钟 | −0.65 | 0.48 |

   四个窗口的形状拟合得同样好，所以数据本身定不出会话时长。真实站点数据的变差函数（在充数差分的方差随滞后增长的速度）粗略指向平均会话约 1–1.5 小时，因此以 60 分钟为中心值。会话时长越长，反推的弹性越大，也越不精确；120 分钟时与 Kuang et al. (2024) 的 −0.76 不矛盾。
4. **设计 C 的估计可以完全由站点平均日内曲线复现**：只保留每个站点的平均日内曲线、不加任何价格效应（到达口径，曲线形状与真实时长相同）时，设计 C 的估计为 −0.37 / −0.63 / −0.65 / −0.52（30 分钟到 3 小时），真实数据为 −0.38 / −0.62 / −0.63 / −0.50，几乎一样。设计 D 在同样的数据上为 −0.04 到 +0.08。设计 C 看到的只是"站点平均曲线在切换时刻的形状"，这一形状里价格效应和作息无法区分。这进一步支持 D9。

**对模型的含义**：
- 锚定值 −0.21（se 0.20）是"切换后 3 小时平均存量响应"的无偏估计，与模型静态设定（`model.price_lags = 0`，β 的含义为 3 小时平均响应，设计文档 6.5）口径一致，**主实验不需要修改**
- 若要表达"价格维持较久后的长期响应"，可以启用滞后核：按平均会话 60 分钟，3 小时窗口因子约 0.59，长期存量弹性约 −0.21 / 0.59 ≈ −0.36，与反推的到达弹性 −0.33 一致。**这是一个待你决定的可选项**（见大纲 6.10）
- 局限：合成噪声在站点之间独立，合成数据上的标准误（约 0.02–0.1）远小于真实数据（0.1–0.2），真实数据中还有小区层面相关的冲击；这不影响偏误的结论，但不能用合成标准误代替真实标准误。另外没有模拟"等低价再充"的跨时替代（负荷转移），它会让切换前后的对比变大而不是变小
